## TL;DR（实地参观后的结论，先放最前）

1. **挑毛是纯视觉任务。** 亲手挑毛确认：用镊子夹毛时**人感觉不到任何有用的触觉**，全靠看。触觉比视觉粗糙太多。→ 原文 §4/§5.1 把"触觉/触觉伺服"捧成核心，**被证伪，降级为脚注**。
2. **真正的失败不是"夹不住"，而是 C 类（碰到前就被推跑）+ 嵌入毛拔不出。** 不是 B 类（夹不牢）。
3. **镊子能夹起毛——人每天都在做。所以别换末端。** 缺的不是工具，是"镊子后面那套让毛不跑的闭环"（接近手法 + 反向约束 + 视觉伺服 + 反应式修正）。
4. **deep research 想把方案引向"换非接触/吸附模态"——对 C 类是南辕北辙**：吸要靠气流，而气流正是把松毛推跑的病因。报告搜偏了微米尺度，对本任务过度悲观。
5. **资源排序**：① 改接近+合拢手法降侧向气流 → ② 压料/张紧给毛反向约束（很可能最强一招）→ ③ 视觉闭环对位 → ④ 感知前端 →（嵌入毛走镊子/带钩"抓住抽出"这条独立支线）。

> 一句话：**问题不是"镊子错了"，是"没有闭环的镊子是个不完整的复制品"。补全闭环，别换工具。**

## 0. 这份文档要回答的两个问题（原始动机）

1. **引入具身智能 / 最新模型的能力，能不能帮我更干净地挑毛？**（前提：机械结构可改，唯一硬要求是"挑拣干净、质量好"）
2. **工人基本都用镊子，朴素地"模仿工人"是不是就该让机器也用镊子？**

> **实地后的回答**：(1) 当下最火的大模型/VLA 帮不上，真正帮你的是把工人那套**闭环**补回来；(2) 该模仿镊子——但更要模仿镊子**后面**那套闭环。详见下文。

## 1. 先把问题归类：这是**接触物理**问题，不是**认知**问题

> **✅ 实地确认（2026-06-07）：本节判断完全站得住，并被进一步坐实。** "夹不起来"不是认知/检测问题（检测当下不是瓶颈），就是末端接触物理问题。§3.1 还会把它精确到"是 C 类推跑，不是 B 类夹不住"。

挑毛的难点**不在**"看懂场景、理解任务、决定先挑哪根"——古典检测（现有 YOLOv8-seg）对这些早就够了。

难点在：**一根近乎无质量的纤维，怎么在不被气流 / 侧向力 / 静电推走的前提下，干净地拿走。** 这是接触力学 + 微气动问题。

**这个归类决定了一切：**

- 当下最火的那部分"具身智能"——大 VLA 端到端策略——恰恰是这个问题的**错误工具**（理由见 §3）。
- 真正能帮上忙的，是**接触模态的改造**和**把传感放到接触点**，而不是更聪明的"大脑"。
- "机械结构可改"这句话，是这里**最大的杠杆**，比任何模型都重要。

> 核心判断：**挑拣质量主要由末端的接触物理决定，不是由大脑决定。** 资源应优先砸在末端 + 接近/约束手法，而不是端到端模型。

## 2. 最大的杠杆：改"接触方式 / 接近手法"，而不是换更聪明的大脑

> **⚠️ 实地修正（2026-06-07）：本节方向对（杠杆在末端接触），但落点要改。** 原文这里倾向"改接触模态"（换吸 / 非接触 / 静电）。实地发现真正的失败是 **C 类（毛在夹到之前被推跑）**，而镊子本身能夹起毛。所以杠杆**不在"换模态"，而在"改接近 + 合拢手法、并给毛反向约束"**——让毛在镊子合拢的瞬间还待在原地。**换吸头对 C 类反而南辕北辙**（吸要靠气流，气流正是病因，见 §3.1）。

对一个一碰就飞的目标，赢的招不是把镊子夹得更准，而是**从物理上让扰动趋近于零**。

### 2.1 "气流悖论"是核心矛盾（实地确认为主因）

末端**任何**移动都会产生扰动近无质量毛的气流。两片镊子**对夹合拢**的瞬间，制造一对相向的侧向气流，正好把松毛推跑——这就是 C 类失败的物理机制，也是实地确认的**主要失败模式**。

所以要攻的是"让毛不被推跑"，按性价比：

1. **改接近 + 合拢手法**（最便宜，可能不动硬件）：慢速接近；接近方向避开会把毛吹走的角度；**重新设计合拢方式**——两片同时对夹 = 制造相向气流，考虑**一片固定、只动另一片**（把毛压向静片），或从侧向切入而非正上方对夹。
2. **给毛一个反向约束**（很可能是最强一招，且是工人偷在用的）：另一只手按住 / 绷紧窝面，让毛没法被推跑。机器侧 = 压料 / 张紧，nova2 压料臂的角色可能要扩（见 §6.1）。
3. **视觉闭环对位 + 实时反应**：毛一动就跟着改。人赢的核心，但比 1、2 贵。

### 2.2 食品安全先砍掉一个选项

**燕窝是高端食品**，所以工业上去细纤维最常用的**粘附（胶辊 / 胶带）直接出局**——残留污染。同理，毛细 / 液桥夹爪（会留液体残留）也出局。

### 2.3 "换模态"为什么对本任务降级了（deep research 的教训）

原文这里列过吸头 / 非接触吸附 / 静电探针等模态。**2026-06-07 的 deep research + 实地数据联合判断：这些对你的主要失败（C 类推跑）不是解药，甚至反向**——

| 模态 | 对 C 类的致命问题 |
|------|-------------------|
| 非接触伯努利 / 吸头 | **要靠气流，而气流就是把松毛推跑的病因**。报告确认伯努利"会把轻件吹飞" |
| 毛细 / 液桥 | 留液体残留 → 食品安全否决 |
| 静电吸附 | 需要接触面积，一根毛几乎不提供；最轻只演示到 ~10g |
| 软体 / 柔顺夹爪 | 最小夹取 ~11mm，比毛大一个数量级，需要"体"可包 |

> 注：deep research 报告搜偏了**微米尺度**（猫毛、微克芯片），对本任务（毫米长毛）过度悲观。它唯一对你有用的两点：① 接触物理的力学框架（方向对）；② "环抱式夹爪从根部缠住"的思路，对**嵌入毛**有参考价值（见 §5.5）。

## 3. 把"具身 / 大模型"工具箱对着三类失败诚实打分

**三类失败定义**：A = 碰不到 / 挑不中（对位）；B = 碰到但夹不起（夹的力学）；C = 碰到（或接近）后推跑了（接近气流 / 侧向力）。

> **✅ 实地确认失败占比（2026-06-07，原 §6.2 的待确认项现已有答案）：**
> - **松毛的主因是 C（推跑）**，不是 B。镊子能夹住毛，问题是夹到之前毛就被推跑了。
> - **嵌入毛是另一条线**：埋在窝体里，是"够不到 / 拔不出"，需要"抓住抽出"（见 §5.5）。
> - A（对位）是次要瓶颈，检测本身当下不是问题。
> → **因为 C 是大头，原 §6.2 的预案生效："改接近 / 约束手法"是第一优先，甚至先于视觉伺服。**

| 技术 | 主要打哪类 | 判断 | 理由 |
|------|-----------|------|------|
| **大 VLA 端到端**（RT-2 / OpenVLA / π0 类） | 核心精细动作 | ❌ **不上** | 精度地板太高（cm 级、~10Hz），sub-mm 够不着；**采数据是死穴**——连人手都难稳定示范"干净挑毛"；且它不解接触物理 |
| **学习策略（全策略 RL/IL）** | 精细动作 | ⚠️ **高风险，缓** | 仿真"无质量可变形纤维 + 气流 + 接触"是地狱级 sim-to-real；遥操作采数据也难 |
| **Residual learning**（脚本动作上叠学习修正） | C 类微调 | ⚠️ **maybe，靠后** | 比全策略可行，但要等基线跑通且有数据 |
| ~~**触觉传感 + 学习触觉**（GelSight / DIGIT 类）~~ | ~~B + C + Z~~ | ❌ **降级（实地推翻）** | **原文把它列为最高价值——实地发现挑毛对人是纯视觉、触觉粗糙到没用。触觉对本任务不是不可能，是没必要。详见 §4。** |
| **视觉闭环 / 视觉伺服** | A + C 的反应式修正 | ✅ **高价值** | 对位 + "毛一动就跟" = 人赢的核心。**取代了原文触觉的位置。** |
| **基础感知模型**（SAM2 / DINO / grounding） | A + B 的难检测样本 | ✅ **低风险可试** | 对密集绒团 / 半埋毛比 YOLOv8 鲁棒，还能少标注 |
| **背光成像**（透射光，非 AI 老 trick） | A + B 检测 | ✅ **便宜，值得试** | 细纤维在透射光下边缘极清晰，大幅提检测信噪比 |

**把信号从炒作里分出来：真正帮你的是视觉伺服 + 更好的感知前端 +（最后的）residual，不是端到端大模型，也不是触觉。**

### 3.1 关键澄清：C（推跑）≠ B（夹不住）

这是本次最重要的精确化。"夹不起来"听上去像 B，实地证明是 C：

- **镊子物理上能夹住一根毛**（人每天做），所以不是"太轻夹不牢"。
- 失败发生在**夹到之前**：合拢气流 / 侧向力把毛推跑了。
- **所以解药是"让毛待在原地"（§2.1 的接近 + 约束手法），不是"换一种能夹住更轻物体的工具"。** 后者解的是 B，而你没有 B 问题。

> **❌ 实地推翻（2026-06-07）。原文这一整节的主张是错的，保留作为"被证伪的判断"以记录演进。**
>
> **原文主张**：从具身智能里只拿一条原则，就是"把'先感知-再开环执行'换成'边接触边感知'，并把传感器装在接触发生的地方（触觉 / 力）"。原文据此把触觉伺服捧为最高价值。

>

> - ~~触觉 / 力 = 传感在指尖，闭接触环~~ → **本任务不需要**。人就是"纯视觉把这活干成"的现成存在性证明。
>

## 5. "工人都用镊子，模仿工人是不是就用镊子？" —— 这是关键的一问

> **✅ 实地后这一节的结论更强了，但要点变了。** 原文论证"镊子只是无源工具，关键在它后面那套闭环（含触觉）"。实地修正：那套闭环里**触觉那一截不存在，是纯视觉闭环**；而"补全闭环、别换工具"的结论不仅成立，还被"人纯视觉用镊子就能干成"直接坐实。

### 5.1 工人用的不是镊子，是"镊子 + 一双手 + 两只眼 + **纯视觉**实时闭环 + 大脑"

镊子只是这套系统里**最不重要、最被动**的一截。真正在干活的是镊子**后面**那套：

- 两只眼的实时视觉伺服 + 立体深度感知，生物级闭环速率持续微调；
- ~~指尖触觉~~ → **实地确认：挑毛对人是纯视觉，触觉粗糙到用不上**；
- 亚毫米级的接近与施力控制——极轻、极慢、极准；
- 柔顺 + 反应——毛一动，手瞬间跟着改；
- 对气流 / 毛翘伏的直觉性**接近策略**（让毛不被推跑，正是 §2.1）。

**镊子本身不提供这些里的任何一个。它是放大人手灵巧度的无源工具。**

### 5.2 现状的根因，一句话（实地后从"论断"升级为"确诊"）

> **模仿了镊子，却没模仿镊子后面那套闭环。复制了最依赖"人"的那一半（工具），丢掉了让它 work 的那一半（视觉闭环 + 接近/约束手法 + 反应）。**

那三类失败，人都不会这样失败——因为人在闭机器没闭的环。**实地数据把这句从猜想变成了确诊：人和机器用的是同一把镊子、同样纯视觉，差别只在人有那套闭环、机器没有。**

### 5.3 "模仿工人"是对的，但要分清模仿**功能**还是**形态**

复制形态、却丢掉形态所依赖的功能，是机器人学最经典的坑：

- **飞机不扇翅膀**——模仿的是"升力"（翼型），不是"羽毛扇动"。
- **轮子在平地赢过腿**——"平地高效移动"这个功能轮子最优。
- **振动料斗**给零件定向——用振动 + 几何让零件自排，无人类对应物，却又快又稳。

共同点：**当你的"身体"和人不一样时，照搬人的形态，等于扔掉你自己的优势。**

### 5.4 但本任务有个反转：这里**该照搬**人的形态（镊子）

注意，§5.3 的"别照搬形态"在**别处**成立，但对**本任务**要小心——因为实地证明：**人用镊子、纯视觉，就能把这活干干净。** 这说明镊子在这个任务上不是"人体约束下的妥协"，而是**对"夹起一根毛"这个子任务的有效工具**。所以本任务的坑不是"用了镊子"，而是"用了镊子却没配闭环"。

> 这一条**修正了原文的倾向**。原文（受"机器有人没有的器官"启发）倾向于"机器该用吸 / 静电这些人没有的模态"。实地后：对松毛的 C 类失败，那些模态反而有害（§2.3）；镊子 + 闭环才是对的。

### 5.5 镊子对嵌入毛**确实必要**（这条原文对了，实地加强）

- **半埋 / 嵌进窝体的毛**：吸根本拔不出来——"抓住再抽出"的动作，镊子（或带钩 / 环抱工具）**物理必要**。deep research 里"环抱式夹爪从根部缠住"的思路对这条有参考价值。
- **松散 / 表面 / 极轻的毛**：失败是 C 类（推跑），解药是镊子 + 接近/约束手法（§2.1），**不是换吸**。

### 5.6 落点：两件事分开决定

1. **工具形态** —— 按毛型可能**不止一种**，但**两种都偏向"夹"系**：
   - 松毛：镊子 + 不产生侧向气流的合拢手法；
   - 嵌入毛：镊子 / 带钩工具，"抓住抽出"。
   - **"按毛型换手法/工具"恰恰是人做不到、机器能做到的优势。**
   - 代码里已有的 straight / curved / dense 分类，本来就该接到"手法选择"上。
2. **闭环** —— **无论哪种毛，都要把工人那套缺失的闭环补回来**：视觉伺服（对位）+ 接近/约束手法（让毛不跑）+ 反应式修正。**（触觉那一截删除——本任务不需要。）**

> 换句话说：问题不是"镊子错了"，而是"**没有视觉闭环和接近手法的镊子，是一个不完整的复制品**"。

### 5.7 "模仿工人"该怎么读

| 该模仿（功能 / 手法） | 不必硬模仿（形态） |
|----------------------|---------------------|
| 闭**视觉**环、持续微调 | ~~一定用触觉~~（人也没用） |
| 接近 / 约束手法，让毛不被推跑 | 一定用一种工具通吃所有毛 |
| 轻接触、慢接近、柔顺 | 一定从正上方下扎 |
| 反应式：目标一动就改 | |
| **工人的接近策略与微观手法** | |

最后一条（工人的微观手法）是**最该去工厂实地挖**的真金——见 §6。

## 8. 这趟讨论对 AutoWeaver（框架侧）的含义

无论选上面哪条，框架含义是**同一个**：传感丰富的闭环 + BT 编排时序与回退 + 安全包络包在外面。这正是 AutoWeaver 一路在搭的东西。

本次讨论（含实地修正）给框架的 primitive 需求清单：

- **视觉误差作为一等传感输入** —— Worker 写进 WorldBoard，leaf 读 snapshot，带新鲜度门。
- **接近 / 约束作为可编排原语** —— "压料臂张紧 → 慢速接近 → 不产生侧向气流的合拢"应能在 BT 层编排为带时序的动作序列。
- **反应式 abort / 重试** —— 毛被推跑（视觉上目标消失 / 位移超阈）应触发 abort + 重新对位，而不是盲目合拢。
- **末端 / 手法按毛型可换** —— BT 层不感知具体工具，按毛型（松 / 嵌入）选手法，就像 `ArmBase` 抽象掉驱动类型。
- ~~**力 / 触觉作为一等输入**~~ → **从清单移除**（本任务纯视觉，§4）。

> **结论：这趟（含实地修正）没动 AutoWeaver 的架构方向，反而验证了"传感丰富闭环 + 可换手法 + 安全 abort"是对的。最大的变化是：把"触觉 / 力"从基建需求里删掉，把"反应式 abort（毛被推跑就重来）"和"接近/约束编排"补进去。**
